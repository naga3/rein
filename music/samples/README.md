# DPCM にする打楽器の録音（2026-11-08）

人の道の曲（human-yottari など）の DPCM のための素材。Music の「音色とサンプル…」で WAV を選んで DPCM にする。

出どころ: VCSL（Versilian Community Sample Library）https://github.com/sgossner/VCSL 。ライセンスは CC0 1.0（リポジトリに明記。作者名の表示は要らない）。

元の録音（44.1kHz・ステレオ・1〜2 秒）から、ここで作り直したもの: モノラルにし、頭の無音を切り（いちばん大きい所の 3% を越えた所から）、短く切って終わりの 35% をなめらかに消し（響きを残さない）、いちばん大きい所を 98% にそろえた。
