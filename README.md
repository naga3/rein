# RE: in CARNATION

死に咲き狂う、輪廻アクション。

**遊ぶ: https://naga3.github.io/rein/**（[itch.io](https://naga3.itch.io/rein) でも遊べます）

題名は Re:incarnation（生まれ変わり）、in carnation（カーネーションの中に）、RE:（もう一度）を重ねたもの。読みは「リインカーネーション」。

## どんなゲーム

- 動きは「走る」と「ダッシュ」だけ。ジャンプはありません
- 死ぬと、その場にカーネーションが咲き、次の生が始まります。死はゲームオーバーではなく、一つの人生の終わりです
- 地獄から始まり、畜生・餓鬼・人・天と、五つの道（五趣）を一つずつめぐります。どの道も、隠された「光の部屋」を 5 つ見つけて死ぬと、次の生は次の道で始まります
- 道のあちこちに看板があり、パーリ仏典の一節が書かれています。看板の窓から、原典のページ（[初期仏典を読む](https://sutta.ponk.jp/)）を開けます
- 上手な人は少ない生まれ変わりで、はじめての人は多くの生まれ変わりを重ねて、最後まで進めます

仏典に書かれていることから明らかに外れたことは、ゲームのしくみに入れないようにしています（範囲は上座部の三蔵と注釈まで）。ゲームとしての脚色や省略はあります。

## 操作

| | PC | スマホ | ゲームパッド |
|---|---|---|---|
| 走る | ←→・A D | 左のスティック | 十字・スティック |
| ダッシュ（8 方向。空中でもう 1 回） | Z・Shift ＋向き | 右半分を押す | B・X・RB |
| 看板を読む | ↓ | スティックを下 | 下 |
| 看板の原典を開く | X | 窓の「原典を開く」 | — |
| ポーズ（つづける・この生を終える・タイトルへ） | Esc | 左上の「ポーズ」 | Select・Start |
| 音を消す | M | — | — |

言葉は日本語と英語（タイトルの「言葉」、または URL の `?lang=ja`・`?lang=en`）。

## 動かす

```
npm install
npm run dev     # http://127.0.0.1:15040/
npm run build   # dist/ に書き出す
```

素の JavaScript ＋ Vite。画面は 320 × 240。地図のエディタは `editor.html`（開発中だけ）。
